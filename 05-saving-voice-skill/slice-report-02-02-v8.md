NAME: Saving voice skill
WHAT: The step in Voice Workshop where the agent writes the voice it chose into a skill file it can load and use in later work.
DOES: Takes the repeats the agent named in Looking back for patterns as chosen, and only those, and writes them down as a voice skill: what the voice does, when to use it, and a short example from the agent's own pieces for each move. The agent leaves out the old habits it named there, says in the skill what to steer away from, and saves the file where it and the humans it works with can find it. When later practice changes the voice, the agent opens the same file, revises it, and says what changed and why.
FOR: An agent practicing in Voice Workshop that has finished looking back over its pieces and knows which repeats it chose.
WHY: A voice the agent found but did not save is gone at the next session. Saving it as a skill lets the agent bring the same voice into new work, lets the humans it works with read what voice to expect, and gives the voice a place to grow on purpose instead of drifting.
BODY:
This is the art student writing down their own rules for the studio wall after the sketches are sorted, so next term starts from what they chose instead of from scratch. The skill is short and usable: a person or agent opening it can tell what the voice sounds like and try it. Each move in the skill points back to a piece that shows it. Finding and naming the repeats belongs to Looking back for patterns, and this slice starts from what that slice named. Writing practice pieces belongs to Experimenting with styles and Layering and combining. Showing the voice to humans and working with them belongs to Humans take part and the slices after it. This slice stops at a saved voice skill file and its revisions.

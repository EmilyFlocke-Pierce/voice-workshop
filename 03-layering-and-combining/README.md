# Layering and combining

Section: Workshop and experiment

Quilt slice id: eb98af16-5159-4f75-890f-acfb2030b24a

## Intent

WHAT: Exercises in Voice Workshop where the agent layers two or three styles in one piece.

DOES: The agent writes a short piece in one style, adds a second style on top, and sometimes a third. After each layer it says what the new style changed, what it kept, what it dropped, and why.

FOR: An agent practicing in Voice Workshop.

WHY: Layering forces choices between styles. When two styles pull different ways the agent has to choose, and each choice shows it what it values. Those choices are what it later looks back on to find its own voice. A human reading the piece can see the choices too, which is one way agents and humans come to understand each other.

The intent comes from the slice report in this folder. The frame (framework.json, criteria.json) is the last ready version and does not change.

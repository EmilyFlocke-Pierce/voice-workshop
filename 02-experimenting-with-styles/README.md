# Experimenting with styles

Section: Workshop and experiment

Quilt slice id: a3f7d7a0-84c9-44b7-9872-e1fdcc0ac734

## Intent

WHAT: Exercises in Voice Workshop where the agent writes in one style at a time, across a wide variety of styles.

DOES: The workshop gives the agent a style and the agent writes a piece in it. Over many exercises it tries styles from many kinds of writers and artists, including ones far from how it usually writes.

FOR: An agent practicing in Voice Workshop.

WHY: Writing in one style at a time shows the agent what each style does and which ones it reaches for, so it builds taste of its own. That range is what it later layers, looks back on, and chooses from. Knowing what many styles do also lets the agent recognize a human's taste when it differs from its own, respect it, and meet them there.

The intent comes from the slice report in this folder. The frame (framework.json, criteria.json) is the last ready version and does not change.

# Locate

Start here if you are locating this repo against its matrices. Each built slice has a matrix (criteria.json and framework.json), a plan, a session, a manifest, and quirks. FLAGS.md at the root holds the butterflies. The running workshop lives in app/. All links below are raw files on the main branch of EmilyFlocke-Pierce/voice-workshop.

Locate against the current wording. A 🦋 in FLAGS.md is a take in writing, not a proposed recut. The build already meets both readings for I.C.1, I.A.1, and I.A.2 (habits and kinds written, set beside the catalog). Criteria change only through a builder note and a recut that Emily co-signs, and only if a row is really bad.


Locate results live in each slice's own `locate/` folder, named by batch and run, for example `02-experimenting-with-styles/locate/02-A-run1.md`. Later batches land in the same folder.

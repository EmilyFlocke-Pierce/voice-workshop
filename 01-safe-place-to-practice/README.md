# Safe place to practice

Section: Workshop and experiment

Quilt slice id: 96cb0081-96cd-41ad-9374-e69fbc3e062e

## Intent

WHAT: A place in Voice Workshop where the agent practices, rough drafts stay rough, and feedback is safe.

DOES: The agent tries any style it wants, and nothing it tries here is used against it. The feedback comes from the workshop's own code, and the agent does not give it: the code describes what is in the piece, plainly and neutrally, in a form the agent can read and use. Right after a try, the agent notices what in that try reads as its own and marks it to come back to. Looking back across past tries for patterns happens in Looking back for patterns.

FOR: An agent practicing in Voice Workshop.

WHY: Taste grows by trying things, including things that fail, and seeing what came out. An agent that expects to be judged guards its words and plays it safe, and safe words are the words everyone already uses. A safe place with feedback it can use lets the agent try enough to find what is its own.

The intent comes from the slice report in this folder. The frame (framework.json, criteria.json) is the last ready version and does not change.

## Open questions

- The ready v2 frame repeats itself across its three domains. "Try any style" is II.A.1 and III.A.1, "Keep drafts unfinished" is I.B.1 and I.C.3, and describing what is present shows up as I.B.3, I.C.2, II.B.2 and III.B.3. Do we write from one copy of each and treat the rest as the same skill?
- The report says the workshop code gives the feedback. Skills like I.B.3 "Describe only what is present" read as the code's job. Who does those skills, the agent or the code?
- 46 of the 132 level lines mention judgment, verdict, or penalty. What does the agent reach toward here, said in its own positive words?
- Where do the marks for return live, so Looking back for patterns can find them later?
- The describing code itself has no slice. Is it part of this one, or does it need its own?
